🪄 Gubah Lagu jadi Not Biola

Ketik judul lagunya, nanti AI yang nulisin melodinya jadi partitur biola lengkap dengan penjarian dan arah bow. Gak perlu muter lagunya, gak perlu mic.

Tulis nada sebagai:

⚡ Pakai langganan Claude lu, tanpa API key

Claude Code jalan pakai langganan lu. Jadi yang dijembatani bukan langganannya, tapi Claude Code-nya: app manggil server kecil di komputer lu, server itu manggil Claude Code. Nol kunci API, nol beli token.

Sekali doang, siapin:

  1. Login Claude Code: buka terminal, ketik claude, terus ketik /login.
  2. Jalanin jembatannya:node bridge/claude-lokal.mjs
  3. Balik ke sini, pencet Gubah. Biarin terminalnya kebuka.

🔒 Jembatannya cuma dengerin 127.0.0.1 (ga bisa dijangkau dari jaringan) dan cuma nerima panggilan dari alamat app ini. Situs lain yang kebetulan lu buka ga bisa nebeng langganan lu.
